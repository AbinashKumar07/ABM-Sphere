The ABM Sphere CMS Bridge connects this dashboard directly to MoMAGIC CMS (content.thefactmagic.com) so that clicking "🚀 Send to CMS" auto-fills all fields in 1 click!

1
Load Extension in Google Chrome:
Open chrome://extensions, enable Developer mode, click Load unpacked, and select the extension folder in this project.
2
Open MoMAGIC CMS:
Have https://content.thefactmagic.com/admin open in any Chrome tab.
3
Click "Send to CMS":
The bridge automatically focuses the CMS tab and independently fills Title, Description, Remarks, TinyMCE HTML Body, URLs, and Meta tags.
